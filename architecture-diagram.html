Expense Tracker Architecture

Split-Brain Architecture: 100% Local Ingestion, 7 Credit Card Parsers, Smart Budgeting Engine & Gemini LLM Fallback

Local Processing First (Split-Brain)

  • • 7 Credit card parsers (BI, GyT, Banrural, Cuscatlán, BAC, FICOHSA, BAM) execute 100% locally.
  • • Simple list parser with context-aware numeric merchant disambiguation (e.g. "40 super 24").
  • • Smart budget builder, realistic generator, and weekly streak gamification computed without network calls.
  • • Deterministic root-cause heuristics explain overspending without cloud AI.

Strict Privacy & Anonymization

  • • Client-side regex scrubs PII (names, DPI, NIT, accounts, IBAN, addresses) before server receipt.
  • • Server-side validators reject unredacted sensitive tokens before any LLM dispatch.
  • • Only anonymized or aggregated totals ever reach Google Gemini Pro.
  • • Server-side API key protection with zero client credential exposure.

Next.js 16 & Resilient Storage

  • • Next.js App Router & Route Handlers with React 19 and Tailwind CSS 4.
  • • 2D resizable dashboard cards with persistent column and row dimensions.
  • • Resilient localStorage with schema versioning and corruption self-healing.
  • • High-performance Node test runner suite with 291 unit tests across 58 test suites.
