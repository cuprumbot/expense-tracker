Expense Tracker Architecture

Split-brain Next.js app: local parsing, multi-currency conversion, batch deduplication; Gemini receives only sanitized or aggregated JSON

Local processing

  • • Multi-file batch queue and deduplication engine
  • • PDF extraction with GTQ and USD multi-currency conversion
  • • CSV column detection with manual mapping
  • • 11-category Guatemalan catalog and subscriptions
  • • Session continuity with selective reset modal

Split-brain boundary

  • • Files are never sent to the LLM
  • • Extract: sanitized text, re-validated on server
  • • Classify: id, description, amount (only if > 10 pending)
  • • Suggestions: aggregated totals and recurring services
  • • Gemini offline: local results + manual classification

Stack and deployment

  • • Next.js 16 App Router, React 19, TypeScript
  • • Tailwind CSS 4, PapaParse, pdf-parse
  • • @google/genai via server Route Handlers only
  • • Hosted on Vercel, source on GitHub
  • • 117 unit tests passing (Node.js test runner)
